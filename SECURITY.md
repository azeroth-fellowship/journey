# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting:
<https://github.com/azeroth-fellowship/journey/security/advisories/new>

Include what you found, how to reproduce it, and the affected component and version. We aim to acknowledge a report
within a week. This is a volunteer project; there is no bounty program.

## Scope

In scope: the addon, the desktop companion (device identity, key storage, deep links, updater), `packages/contracts`
and `packages/api-client`. The hosted website and API are operated from a separate private repository; reports about
them are welcome through the same channel.

## Supported versions

Only the latest release of the companion and the addon receives fixes.
