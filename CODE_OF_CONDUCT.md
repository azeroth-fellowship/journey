# Code of conduct

We want this to be a friendly place to build tools for adventurers.

- Be respectful and assume good faith. Disagree with ideas, not people.
- No harassment, discrimination, personal attacks, or unwelcome sexual attention.
- Keep discussion on topic and constructive. Do not post other people's private information.
- Maintainers may edit, remove or lock comments, issues and pull requests that break these rules, and may ban people who
  repeatedly do so.

To report a problem, contact the maintainers via a private security advisory
(<https://github.com/azeroth-fellowship/journey/security/advisories/new>) and mark it as a conduct report.

This code is adapted in spirit from the Contributor Covenant (<https://www.contributor-covenant.org>, v2.1).
